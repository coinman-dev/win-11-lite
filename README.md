# win-11-lite

PowerShell-сборщик облегчённого установочного ISO Windows 11 из оригинального образа Microsoft.

Скрипт поддерживает профили очистки `safe`, `balanced` и `max`, подготовку русского интерфейса, интеграцию обновлений и winget, а также обход проверок TPM 2.0 и Secure Boot. По умолчанию используется профиль `balanced`, рассчитанный на сохранение обычной работы приложений, Windows Update, Hyper-V, WSL и контейнеров.

## Требования

- Windows с PowerShell 5.1 или новее;
- запуск с правами администратора (скрипт запрашивает их сам);
- Windows ADK с компонентом Deployment Tools;
- оригинальный ISO Windows 11;
- около 30 ГБ свободного места, либо около 45 ГБ при встраивании обновлений.

## Использование

Запустите интерактивный режим:

```powershell
.\win-11-lite.ps1
```

Перед сборкой можно посмотреть распознанный образ и план действий без изменений:

```powershell
.\win-11-lite.ps1 -InputIso .\iso\original.iso -DryRun
```

Пример сборки с русским языком:

```powershell
.\win-11-lite.ps1 -InputIso .\iso\original.iso -Index 2 -DownloadLanguage ru-RU
```

Дополнительные параметры и примеры находятся в справке в начале [`win-11-lite.ps1`](win-11-lite.ps1).

## Проверка

Тесты расположены в `tests/`. Запускайте их из PowerShell в Windows:

```powershell
.\tests\Test-Win11Lite.ps1
.\tests\Test-WindowsBatch.ps1
```

Тесты с guard выполняйте только в тестовой Windows или VM: реальный guard меняет службы, политики и файлы целевой системы.

Результаты сборки, ISO, журналы, временные файлы и скачанные пакеты намеренно исключены из Git.
