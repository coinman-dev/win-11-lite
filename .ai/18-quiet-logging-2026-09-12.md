# Логирование без подробного вывода в консоль

Пользователь попросил не показывать `ПОДРОБНО: dism /English ...` и аналогичный технический вывод при включённом логировании.

- `-Debug`, явный `-LogFile` и выбор журнала в мастере задают VerbosePreference/DebugPreference = SilentlyContinue. Этапы, прогресс, предупреждения и реальные ошибки остаются видимыми.
- Write-DiagnosticLog записывает собственные технические сообщения непосредственно в соседний `<имя>.details.log` (UTF-8 с BOM для чтения в 5.1). Transcript продолжает писать основной `<имя>.log`; совместной записи двух писателей в один файл нет.
- Команды DISM, итоговые сообщения Invoke-ProgressProcess, вывод oscdimg и детали отказов при удалении шрифтов направлены в технический журнал. Не каждый внутренний verbose-запрос cmdlet сохраняется: шум CIM/HTTP подавлен, нужная диагностика пишется явно.
- Собственный `<имя>.dism.log` с LogLevel:4 теперь включается и при LogFile без Debug.
- При ошибке записи технического журнала выдаётся одно предупреждение. Сбой transcript также больше не скрывается. Ошибки DISM не подавляются.
- Без записи логов явный Verbose сохраняет прежний диагностический вывод. Debug:false больше не трактуется как включение Debug. DryRun по-прежнему не создаёт журналов.
- Относительный LogFile разрешается через SessionState.Path относительно текущей папки PowerShell до проверки защищённых путей.

Проверки: основной набор 142 (было 130) на PowerShell 7.6.6 и Windows PowerShell 5.1.19041.7725. Новые проверки реально создают transcript/технический файл и исполняют обёртку Invoke-Dism с подменой исполняемой команды. Проверены отсутствие verbose-записей в результате, команда в файле, фатальный отказ DISM, отдельные писатели, UTF-8, режимы Debug/LogFile/Debug:false и DryRun.

Дополнительно выполнен DryRun исходного ISO (индекс 2) с Debug + Verbose на обеих версиях PowerShell: завершение успешно, строк ПОДРОБНО/VERBOSE/DEBUG в захваченном консольном выводе нет. Логи проверки — `.ai/logging-validation`. Остальные неизменённые наборы ранее прошли в `.ai/oobe-validation`; суммарное число проверок теперь 491 на версию.

Обработка образа, guard, OOBE и установщик Firefox в этой правке не менялись. Новая сборка ISO не выполнялась.
