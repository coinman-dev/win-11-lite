# Контекст проекта win-11-lite

Если в рабочей копии есть `.ai/PROJECT_CONTEXT.md`, прочитай его перед работой: это локальная рабочая память проекта и указатель на результаты проверок. В репозиторий она не входит, поэтому в свежем клоне её нет; тогда опирайся на `README.md`, `CHANGELOG.md`, `COMPATIBILITY.md` и историю Git.

- Общайся с пользователем по-русски. Сообщения сборщика сохраняй на RU/EN.
- `README.md` веди на английском, `README.ru_RU.md` — на русском. Сохраняй в них одинаковую структуру, переключатель языков и актуальный полный список пользовательских параметров.
- `max` — сознательный агрессивный режим; не смягчай его состав. Явное исключение пользователя: сохранять VBScript/Windows Script Host ради скрытого запуска при установке. `balanced` должен сохранять работоспособность обычных приложений и обслуживания Windows.
- `win-11-lite.ps1` — единственный файл проекта: сборщик и встроенный гостевой сценарий в `#region Guest script`. Папок `data/` и `tools/` нет, генераторов нет; правь гостевой код прямо в этой области. Сборщик ничего не читает из соседних папок.
- Guard запускай для проверки только в тестовой Windows/VM или с подменой системных API. Он изменяет службы, политики и файлы целевой системы.
- Не путай подтверждённый результат в VM с проверкой синтаксиса или тестами с заглушками.
- Локальные каталоги `.ai/`, `doc/`, `tmp/`, `log/`, `out/`, `iso/` в Git не хранятся: заметки и рабочая память — в `.ai/`, сохраняемые материалы разбора — в `doc/`, всё удаляемое — в `tmp/`. Не публикуй их содержимое.
